# 对话与证据交互设计

这是一套有记忆的对话系统。首屏让用户继续对话；系统机制在回答旁可检查，记忆管理作为可收起的侧栏。

- 色彩：纸白 #ffffff、雾灰 #f5f7f9、墨蓝 #233748、次级灰 #75818d、记忆青 #297e83、提示琥珀 #a8702d。
- 字体：系统中文无衬线，正文 16px / 1.85；过程 12–13px，灰色但保持可读对比；编号引用 11px。
- 版式：左对话、右检查器；收起检查器后对话居中、最大阅读宽度 800px。助手不套大气泡，用户消息保留浅灰背景。
- 个性：展开处理过程后，短期与长期记忆以曲线汇入证据节点，再流向回答；只对服务已经到达的阶段点亮，不伪造推理或百分比。

```
SimpleMem                         模型状态    记忆面板
              用户问题
✧ 已完成检索 · 0.8 秒  ⌄
  [展开：实际查询 / 记忆汇流 / 阶段记录 / 回放]
直接回答问题。¹ ²
[输入框                                       发送]
```

自检：删除原先抢占顶部空间的五个阶段框，避免通用仪表盘感；保留一个精致的证据汇流图作为识别点。动效仅用于进行中的轨迹与用户触发回放，尊重 reduced-motion。

来源编号解析 Markdown 文本节点，不碰代码和现有链接。弹窗显示回答时的来源快照、原文证据、版本与作用范围；旧回答缺少快照时明确提示，不关联最新回答来源。原生 dialog 提供焦点约束、Escape 和返回触发点。过程说明是真实服务操作摘要，不展示或模拟模型内部思维链。
