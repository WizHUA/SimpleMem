## 性能与效果实验

固定机器、提交、Python/Node 版本、数据集版本、随机种子、配置、模型和 embedding。分别记录写入、抽取、检索、生成耗时，不能用完整流水线耗时替代某一阶段。每个基线报告样本数、并发度、p50/p95、吞吐、错误率；先热身，再交错执行基线/加速条件，保留原始样本。冷启动、缓存未命中与缓存命中分别统计。

检索指标使用独立标注的 gold memory IDs，报告 Hit Rate、MRR、Recall@K、NDCG@K。答案正确率和引用 F1 必须使用有真值的任务；忠实度和相关性可由盲评或独立评审模型评估并标明方法。合成数据仅能证明实现行为，不代表真实长期对话 benchmark 得分。

加速实验同时检验质量不退化、缓存命中率、避免的模型调用数、上下文 token 估计和延迟。估计 token 不能标为 provider 实际计费 token；没有 GPU 采样时显存应记为未测。真实 LLM 有网络抖动，缓存请求还可能等待同一并发计算，不能对每个命中事件声称固定节省时间。

## 商用发布门槛

该系统可作为独立部署与宿主嵌入的交付候选。商用上线仍需部署方完成真实身份系统接入、HTTPS 与密钥管理、数据保留/删除策略、备份恢复演练、目标负载容量测试及真实模型/宿主验收。SQLite 适合受控单实例部署，多副本写入和分布式缓存失效未经验证时不能承诺水平扩展。

课程完整成果还包括 ≥8000 字研究报告、最终答辩 PPT、演示视频和真实宿主验证记录。工程代码、界面和测试通过不自动补齐这些成果。
