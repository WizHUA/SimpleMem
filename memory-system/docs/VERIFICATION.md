真实模型结果来自真实调用与合成测试数据，不是公开基准或用户长期对话数据集。新14题的剩余失败中，检索来源为当前active v2“梧桐会议室”，回答也给出该值，但附带旧地点，违反预设禁用旧词规则；仍保留13/14，不将复核改写成满分。旧十题第9题的日期问题属于另一轮历史实验，不合并统计。

本轮新增故障路径验证：抽取成功后演化失败通过持久outbox恢复，跨重启不重复抽取；问句截断引文及助手回复不能洗成事实；归档/恢复往返后旧revision被拒绝；摘要自然过期不再展示；删库与取消并发时旧快照不能回填投影；实际ASGI断连取消模型且不发送伪result；删除请求重复取消仍等候权威库和派生数据清除。周期维护使用真实过期事件验证执行与关闭。

加速消融合成测试为10次重复仅1次生成、8并发仅1次生成。真实模型冒烟热命中避免1次最终生成，规划仍每次执行。真实向量服务未配置，向量投影由可控协议/并发测试验证，不能将词法改写挑战写成语义检索已验收。

## 交付包

`dist/full-forward-delivery.zip` 包含白名单源码、测试、文档、前端构建、当前后端wheel及 `MANIFEST.sha256.json`。不包含私有 `.env`、运行数据库、模型密钥或依赖目录。通过 `scripts/package_delivery.py` 重建。

部署前仍需课程宿主、实际身份系统、HTTPS、目标容量、真实 embedding 服务、数据保留策略和恢复演练验收。当前实现是受控单节点交付版本，未声称已验证多副本水平扩展。
