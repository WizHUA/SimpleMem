## 复现命令

```powershell
conda run -n simplemem-agentmemory python scripts/evaluate.py --repeats 10 --output docs/EVALUATION.md
```

机器、并发、候选数、追踪开销都会改变延迟。真实宿主、真实模型回答正确率/忠实度/引用F1、长时间负载仍需独立验收，不由这些合成结果替代。
