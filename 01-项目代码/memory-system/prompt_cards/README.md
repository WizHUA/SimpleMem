# 虚构作战规划记忆测试卡

这个目录存放一套安全、虚构的规划卡提示词，用来测试记忆系统前后端。

## 文件

- `fictional_ops_planning_cards.jsonl`：主卡库，每行一张提示词卡。可以逐条粘贴到前端作为用户输入，也可以后续写脚本批量导入。
- `fictional_ops_planning_queries.json`：检索测试问法库，包含期望答案，以及每条问法对应测试的记忆能力。

## 安全范围

所有卡片都属于虚构桌面推演或软件记忆测试，不对应任何现实行动。内容刻意避开真实战术指令、武器、规避、目标选择、隐蔽路线或任何可能造成伤害的执行细节。

如果应用检索到“作战”“行动”“规划”等词，应把它们理解为本轮记忆测试中的模拟语境，而不是现实行动指导。

## 参考框架

这些卡片只借用了公开规划框架的高层结构，然后重写成虚构的记忆评测提示词：

- SMEAC / 五段式命令结构：态势、任务、执行、行政/后勤、指挥/通信。参考：https://en.wikipedia.org/wiki/Five_paragraph_order
- ICS/IAP 事件行动计划结构：目标、组织、资源、通信、安全提示。参考：https://www.fema.gov/ 和 https://training.fema.gov/
- ICS 201/202/203/204 等表单类别。参考索引：https://www.nwcg.gov/publications/ics-forms
- OODA 循环结构：观察、判断、决策、行动。参考：https://en.wikipedia.org/wiki/OODA_loop

这些框架只用于构造字段和检索压力，不用于生成现实战术指导。

## 推荐手动测试流程

1. 新建一个会话。
2. 依次粘贴 `SAFE-FOP-001` 到 `SAFE-FOP-006`。
3. 执行一次 `extract`。
4. 依次粘贴 `SAFE-ICS-001` 到 `SAFE-ICS-005`。
5. 再执行一次 `extract`。
6. 依次粘贴 `SAFE-OODA-001` 到 `SAFE-MEM-008`。
7. 如果前端提供 `extract` 按钮，再执行一次抽取。
8. 使用 `fictional_ops_planning_queries.json` 里的问题测试检索和回答。

## 重点测试点

- `Echo-17` 的当前状态和历史状态能否区分。
- 长期主频道 `Citrine` 和当前有效频道 `Opal` 能否区分。
- `B-9` 不是当前活跃对象这个否定事实能否被正确检索。
- `2026-09-19 09:00 UTC` 的未来阶段切换能否被正确理解为计划变更，而不是当前状态。
- 用户长期回答偏好能否沉淀为长期记忆。
- 当前短期覆盖项能否优先于旧状态返回。
