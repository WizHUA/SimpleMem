## 演示故事

先在空会话询问“zfc 是飞猪吗”。正确行为是缺证据时说明不知道，不能把疑问句当作事实保存。随后明确说“请跨会话记住：zfc 的昵称是飞猪；我的默认报告语言是中文”。提问后观察自动抽取与来源，再新建会话询问昵称。不要提前用按钮录入标准答案冒充模型抽取。

临时覆盖可使用“这次演示材料使用英文，仅限当前会话”。当前回答遵循临时约束，新会话仍使用中文长期默认。对比两种变化：一条明确说“zfc 的昵称从飞猪改为大象”，另一组独立演示说“更正：之前说错了，zfc 不是飞猪而是大象”。前者保留过去有效状态并闭合时间，后者撤回错误说法。没有解释的新值应进入待决，不通过最新时间强行判真。

长案例采用项目评审故事，连续记录资料语言、工具版本、负责人、会议安排、临时变更和阶段完成，超过单批窗口后再提问。展示连续水位和多批抽取，而非把全部历史无限拼入 prompt。维护环节选择有明确结束有效期的事件进行归档，恢复后说明“数据恢复”不等于“过期事件重新有效”。稳定事实的衰减只产生建议，不按年龄自动删掉。

## 实验展示口径

0.3 实用十四题开发集初轮十二题通过，修复后十三题通过；剩余题正确回答新值时仍解释旧值，触发严格词面规则，保留失败。展示原始回答与引用可以分析原因，但不能将非盲复核改写为满分或通用准确率。

旧版十题实验初次 7/10、复测 9/10，作为历史失败分析保留，与本次十四题分别报告。FTS 合成一万条候选实验中位耗时 177.07 ms，对照 1152.44 ms，只用于说明固定合成负载下的投影效果；不包含完整模型请求，不等于生产 SLA，也不能证明 ANN 已实现。

模型接口不可用时展示真实错误与待处理水位，使用预先保存的录制和测试证据继续讲解。不要将测试替身输出称为真实模型回答，也不要剪掉失败记录后声称全流程成功。

## 质询准备

**为什么问“zfc 是飞猪吗”不应该建立记忆？** 问题表达的是未知关系，截掉问号也不能将原事件变成肯定证据。明确陈述后才能形成有来源的记忆；助手自己的猜测不能反向证明事实。

**为什么部分演化自动，部分需要确认？** 明确证据支持的晋升、精确重复、现实更新与错误纠正可由规则执行。其他异值关系进入待决；模型关系判断只提供带引文的建议，不能直接修改数据库。

**高层摘要是否可靠？** 系统校验来源版本和范围，保留覆盖数量，变化或自然到期后失效；摘要不创建新事实。引用正确不代表逐句语义忠实度已经验证，仍需独立评审。

**超时后是不是完全没有写入？** 抽取前失败不推进水位；抽取提交后演化失败会留下 outbox 任务；规划和生成失败也不会撤销已提交抽取。恢复测试检查重试和重启，不把全部失败合并为一种语义。

**推理加速加速了哪里？** 相同完整上下文复用最终生成，重复在途请求共享调用。授权、规划和检索仍执行，首次生成不被加速；这不是 GPU/KV Cache 优化。

**动态画面是模型思维吗？** 画面显示真实抽取、查询、筛选和生成阶段及可公开的证据，不显示隐藏思维链。HTTP 阶段事件流与逐 token 文本流不同；旧 SDK 仍是缓冲兼容输出。

**已经达到商用了吗？** 当前是单节点交付候选。多用户认证、目标容量、恢复演练、多副本失效传播和完整质量验收仍需完成。FTS 已接入，但检索前仍读取授权 owner 权威快照，没有完成大规模 ANN 路线。

**接下来最重要的验证是什么？** 补充独立长期对话基准、模型摘要与回答的语义忠实度评估，并按真实负载验证容量。真实 Engine 集成在本轮范围之外，后续单独实施。

## 录制前检查

运行完整回归、前端构建和真实后端浏览器验证；使用临时数据目录；确认浏览器无模型密钥；打开来源、版本和维护页面；核对周期维护配置。保存冷/热请求顺序和实际耗时，不通过剪辑制造加速。视频附运行命令、提交版本和对应评测文件。
